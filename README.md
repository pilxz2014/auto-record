# Android 自动化脚本编辑器

通过 **adb** 自动化操作 Android 设备：定位点击、清空输入框、输入账号密码（支持中文）、自动切换下一个输入框等。编辑好的脚本可**导出为独立 shell 脚本**，脱离编辑器直接运行。

## 启动

```bash
cd D:\test
pip install flask        # 唯一依赖
python server.py
```

浏览器打开 **http://127.0.0.1:5000**

## 界面说明

所有动作都是通过**步骤编辑弹窗**统一创建/编辑：点底部「添加步骤」、步骤卡片上的「＋在此后插入」、✏️ 编辑，或**点截图 / 点控件蓝框**都会弹出同一个窗口，在里面选动作类型、填名称备注、填内容（坐标或目标控件会自动带入）。

- **左侧**：步骤列表（每步下方有「＋在此后插入」可**任意位置插入**；▶ 单步试跑、✏️ 编辑、⬆⬇ 排序、⧉ 复制、🗑 删除）
- **右侧截图面板**：
  - **📍 坐标模式**：点击截图 → 弹出编辑窗，坐标已自动换算好（点控件也可在坐标模式用）
  - **🎯 控件模式**：截图上叠加控件蓝框 / 下方可搜索控件列表，点击 → 弹出编辑窗，resource-id/文字已自动带入
- **顶栏**：设备选择、IME 状态灯（ADBKeyboard）、保存/打开脚本、导出 .sh、运行整个脚本
- **🖥 scrcpy**：打开设备实时镜像，运行时可实时观察

## 支持的步骤类型

| 步骤 | 说明 | 底层命令 |
|---|---|---|
| 点击 (坐标) | 固定坐标点击 | `input tap x y` |
| 点击 (控件) | 按 resource-id 或文字定位 | `uiautomator dump` → bounds 中心点 |
| **点击并清空** | 聚焦目标输入框 + 清空，一步到位 | tap + 批量 DEL（同步）+ 回读校验 |
| **点击并输入** | 聚焦 + 清空 + 输入文本，填账号密码最常用 | tap + 清空 + input + 回读校验 |
| 输入文本 | 输入期间自动接管输入法 | 英数走同步 `input text`，中文走 ADBKeyboard/YADB |
| 清空输入框 | 清空当前聚焦的输入框 | MOVE_END + 批量 DEL（一次 adb 调用发完，同步） |
| 按键 | TAB 切到下一个输入框等 | `input keyevent` |
| 滑动 / 等待 / 启动App / 返回 / Home | | `input swipe` / `motionevent` / sleep / `am start` 等 |

> **滑动轨迹录制**：在「📍 坐标模式」下，**按住截图直接拖动**即可实时记录整条轨迹和拖动速度，
> 松手自动生成一条「滑动」步骤（存储所有轨迹点 + 总时长）。运行时用 `input motionevent`
> 按记录的点和速度还原（Android 12+），不支持时自动回退为首尾单段滑动。导出的 .sh 用 `swipe_traj` 同样还原。

> **自动收起键盘**：脚本属性里有「收起键盘」勾选框（默认开）。输入完成后自动发 BACK
> 收起软键盘（ADBKeyboard 或自带输入法都管），避免键盘挡住下一步点击。后端执行与导出的 .sh
> （`HIDE_KEYBOARD=1`）都有效；取消勾选则不收键盘。

> **小技巧**：截图面板上方有「点这里 / 点这里并清空 / 在这里输入」动作选择器。
> 想「清空账号框后输入」，选「👆 点这里并清空」点账号框即可生成一条组合步骤；
> 想直接填某个框，选「⌨️ 在这里输入」点该框，会弹出输入框让你填内容，自动生成「聚焦+清空+输入」。

## 文本输入与清空（重要：运行期间会临时接管输入法）

**为什么会"输英文数字结果变成中文"**：`adb shell input text` 是把字符拆成按键事件注入的，而拼音类输入法
（讯飞/搜狗/百度）会把这些字母按键当成拼音去组词 —— 于是 `20260001` 进框变成 `啊安…`，数字还会被
候选缓冲吞掉。密码框（`inputType=textPassword`）不参与组词，所以以前的表现时好时坏。

**为什么清空会"没生效"**：清空原来走 ADBKeyboard 的 `ADB_CLEAR_TEXT` 广播，而 `am broadcast` 是
"喊完就走"——命令返回时输入法还没处理，紧接着的输入会和它抢顺序。于是时而没清干净（内容一直往后
累加）、时而刚输进去的字又被清掉，换台设备/换个 ROM 表现还不一样。**现在清空一律用同步的按键方式**
（`MOVE_END` + 批量 `DEL`，一次 adb 调用发完），命令返回时按键已处理完，不再有竞争。

**现在的统一做法**（后端执行与导出的 .sh 完全一致）：

1. **输入期间接管输入法**：
   - 装了 ADBKeyboard → 切到它（它只转发广播、不组词，按键原样落字），结束后自动切回你的输入法
   - 没装 → **临时关闭输入法**（`ime disable`），脚本结束（含出错、Ctrl+C 中断）自动恢复
2. **英文/数字**：同步 `input text`，不再依赖广播
3. **中文**：ADBKeyboard 广播 > YADB 免安装粘贴（两者都是异步，所以会回读界面确认，没进去就重发一次；
   部分 ROM 如华为 HarmonyOS 会拒绝注入 Ctrl+V，YADB 会直接报错提示装 ADBKeyboard，不假装成功）
4. **每一步都回读校验**：
   - 清空后读一次控件文本；没干净就自动补发一轮按键，仍不干净再用广播兜底，并在日志里给出警告
   - 输入后读一次；没落进控件、或旧内容还在（=清空没生效）→ 自动整段重试一次
   - 密码框只能读到掩码，按"非空"判定，不做明文比对（否则会误报失败）
5. **日志会标出实际走的路**，例如 `聚焦xx → 清空[按键清空] → input 20260001 ·按键注入`，
   失败时直接写明"框内现在是 xxx"，排查不用猜

> 代价：每步多读一次控件树（约 1~2 秒）。换来的是"失败能被发现并自动补救"，不会再静默出错。

**中文输入方案（二选一）**

**方案 A：ADBKeyboard 输入法（最稳，推荐）**

1. 下载 APK：https://github.com/senzhk/ADBKeyBoard/releases/latest/download/ADBKeyboard.apk
2. 放入 `adbkeyboard/ADBKeyboard.apk`
3. 点击编辑器顶栏红色的 **IME ✗** → 自动安装并启用，变绿即可

手动命令（等效）：

```bash
adb install -r adbkeyboard/ADBKeyboard.apk
adb shell ime enable com.android.adbkeyboard/.AdbIME
adb shell ime set com.android.adbkeyboard/.AdbIME
```

**方案 B：YADB（免装 App，适合限制安装应用的设备）**

只需一个文件，push 到 `/data/local/tmp`，不安装任何应用：

1. 下载：https://github.com/ysbing/YADB/releases （或直接用项目里已下载好的 `yadb/yadb`）
2. 放到项目 `yadb/yadb`（编辑器自动用）；导出的 .sh 则放到**脚本同目录**
3. 注意：能不能用取决于 ROM 是否允许注入 Ctrl+V，不行时请改用方案 A

> 纯英文/数字脚本**什么都不用装**：即使设备完全不允许安装应用，也能正常输入。

## 导出的 shell 脚本

导出文件在 `exports/<脚本名>.sh`，自包含（内嵌全部工具函数），Git Bash / Linux / macOS 通用：

```bash
cd D:\test
./exports/登录脚本.sh
```

脚本开头可改 `STEP_DELAY`（步骤间隔秒数）、`HIDE_KEYBOARD`（输入后是否收键盘）、
`FILL_RETRY`（清空+输入后回读校验没通过时自动重试的次数，默认 1）。

**设备选择**：导出的脚本不绑定设备，运行时动态确定：

```bash
./exports/登录脚本.sh              # 自动检测: 1台直接用, 多台列出菜单让你选序号
./exports/登录脚本.sh RXRJ480607150007   # 用第1个参数指定设备
SERIAL=RXRJ480607150007 ./exports/登录脚本.sh   # 用环境变量指定
```

- 0 台在线：报错并给出 USB 调试 / 授权 / `adb kill-server` 排查提示
- 非交互终端连了多台：报错并提示用参数或 `SERIAL=` 指定

**依赖提示**：脚本开头会检查 `adb`、`dirname`、`awk`、`grep`、`sed`、`tr`，缺哪个直接提示怎么装（adb 缺失会给出 platform-tools 下载地址）。

**输入法接管提示**：只要脚本里有写/删文本的步骤，启动时会打印走哪条路（`已切到 ADBKeyboard` 或
`已临时关闭输入法`），并在脚本结束（含出错、Ctrl+C）时自动恢复你的输入法。含中文的脚本若设备既没有
ADBKeyboard 也没有可用的 YADB，会在启动时直接报错说明怎么装，不会跑一半才失败。

**清空/输入自检**：导出的 .sh 里 `clear_text` / `fill_field` 会在动作后回读控件文本 ——
清空不干净自动补发按键（必要时广播兜底），输入没进去自动重试，仍不行会在 stderr 打警告
（`[输入] 警告: 输入后回读校验没通过...`），而不是静默跑错。

## 已保存的脚本

`scripts/` 目录下是 JSON 格式（编辑器内部格式），可随时重新打开编辑再导出。

## 注意事项

- **敏感信息**：脚本 JSON 和导出的 .sh 里明文包含账号密码，**勿提交到公开仓库**
- `uiautomator dump` 在游戏、自绘界面（如部分 Flutter 页面）拿不到控件树，这类场景只能用坐标模式
- 多设备连接时，先在顶栏下拉框选中目标设备
- scrcpy 路径默认为 `D:\Program Files\scrcpy-win64-v3.3.4\scrcpy.exe`，或放在 PATH 中
